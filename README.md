# 요금설계 (kr.co.rateplanner)

ponsale.co.kr 간편신청서(form.php)를 폰 · 태블릿에서 쓰는 안드로이드 앱 (배포용).

## 여는 방법
1. 이 폴더를 **영문 경로**에 둔다 (예: C:\dev\RatePlanner) — 경로에 한글이 있거나 OneDrive 폴더면 빌드 오류
2. Android Studio → File → Open → 이 폴더
3. Gradle 동기화 후 ▶ 실행

## 화면 구성
- 위쪽 제목줄 없음 : 신청서가 화면 전체를 씀
- 사이드바
  - 폰 : 왼쪽 가장자리 손잡이(›)를 누르거나 왼쪽 끝에서 밀면 열림
  - 태블릿 · 폴드 펼침(가로 600dp 이상) : 왼쪽에 항상 보임
- 사이드바 위쪽 : 로그인한 판매점 · 판매자 · 아이디 (신청서 페이지의 상단바는 앱 안에서 숨김)

| 사이드바 메뉴 | 동작 |
|---|---|
| 무선 신청서 | form.php |
| 유선 신청서 | form.php?mode=wired |
| 통신사 서식지 출력 | 신청서의 [통신사 서식지 출력] 버튼과 같음 |
| 수납 요청서 | 신청서의 [수납 요청서] 버튼과 같음 |
| 새로고침 | 지금 화면 다시 불러오기 (화면 맨 위에서 당겨도 됨) |
| 로그아웃 | 로그인 정보 삭제 후 로그인 화면으로 |

- 서버 주소 : app/build.gradle.kts 의 BASE_URL (앱 안에서는 바꿀 수 없음)
- 메뉴를 옮기거나 회전 · 폴드 접기/펼치기를 해도 입력 내용 유지
